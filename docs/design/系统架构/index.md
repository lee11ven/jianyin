# AI 手语转语音实时播放

面向听障/哑语场景：端侧提取手语关键点 → 云端识别为文本 → 流式 TTS → 手机 App / 语音穿戴实时播放。

> 本期交付为**架构设计文档**，不包含业务代码实现。

## 产品定位

- **问题**：听障人士用手语表达时，听力正常方难以即时理解。
- **方案（方案 A）**：摄像头画面在**端侧**做关键点提取，**不上行原始视频**；云端只收关键点序列做识别，再流式合成语音下发播放。
- **手势库**：维护中文手语（CSL）词条与版本化特征，支撑有限词表演示识别与后续生产模型替换。

## 交付分期

| 期次 | 范围 | 架构目标 |
|------|------|----------|
| **第一期** | Flutter App + 云端 | **最小闭环**：App 本地 MediaPipe → WebSocket 上行关键点 → 识别 → WebSocket 下行字幕 + 二进制音频流 |
| **第二期** | 硬件摄像头 + 语音穿戴 | 边缘本地抽点；穿戴收听 WS 音频流；App 保留控制与字幕 |

一期演示**不依赖**穿戴在线；穿戴侧仅冻结契约并用 mock 验收。

## 技术决策

| 项 | 选择 |
|----|------|
| 客户端 | Flutter 跨端 App（一期 UI / 本地抽点 / 播音） |
| 采集与特征 | **方案 A：端侧关键点**；禁止主路径上传原始视频 |
| 播音端 | 一期：App；二期：增加穿戴 |
| 推理 | 云端时序模型（输入为关键点序列，可替换） |
| TTS | **流式合成**，经 WebSocket 二进制帧下行 |
| **实时通道** | **仅 WebSocket**（关键点上行、字幕/控制、音频流下行） |
| REST | 鉴权、建会话、词表、设备、历史（非实时媒体） |
