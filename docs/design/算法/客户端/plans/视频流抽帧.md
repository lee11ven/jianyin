# 视频流抽帧 · 最小可落地单元

> 落地切片计划。算法全文见 [../视频流抽帧.md](../视频流抽帧.md)。本单元只交付「活动段时钟 + 基础质量门控」，驱动同拍感知。

**执行序号：①**（最先）。总序见 [index.md](./index.md)。其后：② [多器官配合](./多器官配合.md) → ③ [运动轨迹](./运动轨迹.md) → ④ [帧手势骨架提取](./帧手势骨架提取.md) → ⑤ [左右手骨架提取](./左右手骨架提取.md)

## 技术栈

| 项 | 选型 |
|----|------|
| 运行时 | Flutter / Dart，`jianyin_app` |
| 采集 | `camera`：`CameraController.startImageStream` → `CameraImage` |
| 运动能量 / 清晰度 | Dart 侧 Y 平面帧差 `E` + Laplacian 方差 `S`（isolate 可选） |
| 调度 | 放行后调 `PerceptionPipeline.tick` |

## 第三方库

| 库 | 用途 | 状态 |
|----|------|------|
| [`camera`](https://pub.dev/packages/camera) `^0.12` | 后置预览与图像流 | **已在** `pubspec.yaml` |
| [`image`](https://pub.dev/packages/image)（可选） | 调试转码 / ROI 灰度 | 按需加；MVP 可直扫 Y 平面 |
| MediaPipe | 本单元**不**跑关键点 | 留给 ②④ |

## 目标 / 非目标

| 项 | 说明 |
|----|------|
| 目标 | `Idle` / `Active` 状态机；清晰度 `S` 拒手形；输出放行元数据；`Active` 按间隔调用 `PerceptionPipeline.tick` |
| 非目标 | 完整 A1–A8 深度/偏向阀门标定、IMU 抖动、PeakHold 精细峰值窗、多候选主说话人打分 |

## 输入 / 输出契约

| 方向 | 内容 |
|------|------|
| 输入 | Home 后置相机预览流（仅本地）；可选上一拍骨架 `low_quality` 反馈 |
| 输出（放行） | `{ ts, sharpness, roi, hand_state, viewpoint_class, motion_energy }`；MVP 固定 `viewpoint_class = N0` |
| 输出（拒手形） | 本拍不送骨架；可仍调 tick 以保住 path/body（由下游决定） |
| 钩子 | 重抖/机位红档占位：调用 tick 时传 `forcePathGap: true` |

不发明新协议字段；不上行原视频。

## 落地步骤

1. 在 `lib/camera/` 实现抽帧状态机：`Idle`（低采样探测运动）↔ `Active`（目标约 20–30 Hz）。
2. 每帧算手 ROI（或全图降采样）运动能量 `E`；过 `T_onset` 且持续 ≥2 帧 → `Active`；静默 `T_quiet` → `Idle`。
3. ROI 灰度 Laplacian（或等价）得 `S`；`S < S_min` → 本拍不送手形（下游骨架省略 `hands`），活动段仍可 tick。
4. 粗检人手 / 沿用上一 ROI，更新 `hand_state ∈ {none,left,right,both}`（切换需连续 `N_stable` 帧）。
5. `Active` 且距上次输出 ≥ `Δt_active`：把帧引用 + 元数据交给 `PerceptionPipeline.tick`；`Idle` 停发 path（不调活动段 tick，或显式不采样轨迹）。
6. 暂无完整抖动/机位阀：预留 `forcePathGap`；MVP 可恒为 false，或用简易全图帧差阈值冒充「重抖」。

## 验收口径

| 指标 | 通过线 |
|------|--------|
| 活动段 tick | `Active` 期间有稳定、均匀的 `PerceptionPipeline.tick` 调用 |
| 模糊拒手形 | `S < S_min` 的帧不进入手形打包（可观测省略 `hands`） |
| Idle 停 path | 回 `Idle` 后不再产生活动段 `path` 节拍 |
| 元数据齐全 | 每次放行含 `ts`、`hand_state`、`viewpoint_class=N0` |
