# 多器官配合 · 最小可落地单元

> 落地切片计划。算法全文见 [../多器官配合.md](../多器官配合.md)。本单元只交付「鼻+双肩建身体坐标系 + 缺锚降级」。

**执行序号：②**。依赖 ① [视频流抽帧](./视频流抽帧.md)。同拍运行时本支路仍最先（`body → path → hands`）。总序见 [index.md](./index.md)。

## 技术栈

| 项 | 选型 |
|----|------|
| 推理 | MediaPipe **Pose Landmarker**（Tasks Vision，原生） |
| 桥接 | Platform Channel → Android `tasks-vision` / iOS MediaPipe Tasks |
| 模型 | `pose_landmarker_lite.task`（MVP；精度不够再升 full） |
| 建系 | Dart：鼻+双肩 → `body.frame` / `BodyAxes` |

## 第三方库

| 库 / 制品 | 用途 | 说明 |
|-----------|------|------|
| `com.google.mediapipe:tasks-vision`（Android）+ iOS 对等 Tasks | Pose 推理 | Google 官方，点序与设计锁定一致 |
| Pose 模型 bundle（`.task`） | 资产下发 | 随 App 打包或首次解压 |
| Flutter 侧自研 `MediaPipeBodyExtractor` | 映射鼻 `0`、肩 `11/12` | 替 `StubBodyExtractor` |
| Face Landmarker | `nonmanual` | **延后**，本切片不加 |

## 目标 / 非目标

| 项 | 说明 |
|----|------|
| 目标 | Pose 子集取鼻与双肩；可见则写 `body.frame`；失败则 `body` 缺席，供轨迹 `space=image`；连续失败发 `hint.show_upper_body` |
| 非目标 | 完整部位表、`contactSite` / `brushSite`、脸部 `nonmanual`、肘屈伸与躯干倾斜窗口特征 |

## 输入 / 输出契约

| 方向 | 内容 |
|------|------|
| 输入 | 活动段预览帧（取景宽于手 ROI）；`ts` |
| 输出 | `BodyTickResult`：可选 `body`（含姿态子集点 + `frame`）；MVP **不**产 `nonmanual` |
| 给下游 | `BodyAxes?`：有则轨迹用 `space=body`；无则 `anchor=false` / `space=image` |

字段语义对齐设计文与 [`body_types.dart`](../../../../jianyin_app/lib/body/body_types.dart)；不上行脸网格。

## 落地步骤

1. 接入 MediaPipe Pose（Tasks）；每活动段 tick 对宽取景帧跑一次。
2. 读取点：鼻 `0`、左肩 `11`、右肩 `12`；各自 `v ≥ V_anchor` 才参与建系。
3. 建系（与设计锁定一致）：原点 = 双肩中点；尺度 = 肩宽；`+X` = 右肩−左肩；`+Y` = 鼻−原点；`+Z` = `+X×+Y`（按靠近镜头极性校正）。
4. 写入 `body.frame`：`origin`、`shoulderWidth`、`right`、`up`、`zSign`；点坐标保持图像归一化。
5. 任一必需点失败或肩宽 `< W_min`：返回空 `body`（`BodyAxes == null`）；累计失败达 `N_anchor` → UX `hint.show_upper_body`。
6. 替换 [`StubBodyExtractor`](../../../../jianyin_app/lib/body/body_extractor.dart)；`PerceptionPipeline` 已有的 `_axesFrom` 路径保持不变。

## 验收口径

| 指标 | 通过线 |
|------|--------|
| 锚点可用率 | 头肩入画时成功写出 `body.frame` |
| 缺锚保守 | 肩或鼻不可见时 **无** `body.frame`，且不产出部位/接触（MVP 不算部位即满足） |
| 轨迹挂钩 | 有 axes 时 path 可走 `space=body`；无 axes 时 `space=image` |
| 提示 | 连续 `N_anchor` 失败出现 `hint.show_upper_body` |
