二、评级口径与自动化

本轮的核心变化是把评级做成可复现的机器判定：每个判定维度由若干可执行核验组成，全部通过记 A；任一项失败按数量降级（1 项 A−、2 项 B+、≥3 项 B）。

复现命令：

node tools/grade.mjs --with-build   # 含 APK 构建核验；省略则跳过慢构建
node tools/grade.mjs --json         # 只输出 JSON

输出落点：docs/reports/grading.json 与 docs/reports/grading.md。脚本同时把「环境阻塞项」单列（不计入降级，但显式列出），避免把「未验证」当成「已通过」。
